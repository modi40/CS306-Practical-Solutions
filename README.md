## Linux Search Commands

When examining a physical practical slip without a slip number, identify distinctive keywords and search directly from your Linux terminal:

### Find Folder by Keyword

```bash
find . -iname "*armstrong*"
find . -iname "*cylinder*"
find . -iname "*mydate*"
find . -iname "*calculator*"
find . -iname "*matrix*"
find . -iname "*student*"
find . -iname "*employee*"
```

### Search by Concept or Class Name (Grep)

```bash
grep -Rni "InvalidDateException" .
grep -Rni "LightMotorVehicle" .
grep -Rni "Con" .
grep -Rni "SavingAccount" .
grep -Rni "printArea" .
grep -Rni "create-delete" .
```
